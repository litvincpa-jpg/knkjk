# Zuma Luma

Яркий русскоязычный сайт развивающих игр для детей 3–7 лет на React, Vite и TypeScript.

## Что работает

- **«Весёлая математика»** — 6 уровней: счёт, сложение, вычитание, сравнение и числовые последовательности. В каждом уровне 6 случайно создаваемых заданий, подсказки, озвучка и звёзды.
- **«Знакомство с буквами»** — 6 уровней и 23 слова: первая буква, картинка по букве и пропущенная буква.
- **«Найди пару»** — 3 размера поля (6, 8 и 12 карточек), проверка совпадений, число ходов, рекорды и звёзды.
- Возрастная программа, интерактивный пример, родительский прогресс, необязательный локальный профиль, FAQ и интерактивное превью игры.
- Адаптивная навигация, клавиатурное управление в играх, поддержка `prefers-reduced-motion`.

## Маршруты

- `#/games/math`
- `#/games/letters`
- `#/games/pairs`

Прогресс хранится локально в браузере. Серверный аккаунт, оплата, микрофон и отправка данных ребёнка не используются. Все три игры бесплатны.

## Разработка

```sh
npm install
npm run dev
npx tsc --noEmit
npm run build
```

Продакшен-сборка формируется в один автономный `dist/index.html`: код, стили, шрифт Nunito и изображения встроены в файл. Русская озвучка использует голосовой синтез браузера, поэтому сеть для неё не требуется.
