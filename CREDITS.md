# Материалы Zuma Luma

- Сцена главной страницы с монстриками, фиолетовый герой Люма, игровой луг, пенёк и фон библиотеки — иллюстрации, созданные специально для этого проекта.
- Картинки предметов и слов в играх — Microsoft Fluent 3D Emoji, лицензия MIT: https://github.com/microsoft/fluentui-emoji
- Шрифт — Nunito Variable через `@fontsource-variable/nunito`, SIL Open Font License.
- Интерфейсные значки — Lucide, лицензия ISC.
- Звуковые эффекты синтезируются локально через Web Audio API. Реплики героев озвучиваются русским голосом браузера; внешние аудиосервисы не вызываются.
